# Angel Detailing

Сайт студии детейлинга в Санкт-Петербурге: услуги, галерея работ, автомобили, отзывы и контакты.

**GitHub Pages:** https://vantak52.github.io/angel-detailing/

## Разработка

```sh
python -m pip install -r requirements.txt
python build.py
node serve.mjs
```

Открыть http://127.0.0.1:4173. Готовые страницы и изображения находятся в `dist/`, шаблон главной — в `templates/home.html`, исходные данные — в `content/*.json`.

## Публикация

После изменений отправьте код в ветку `main`. GitHub Actions соберёт страницы, подготовит ссылки для `/angel-detailing/` и опубликует сайт через GitHub Pages.

Экспорт можно проверить локально:

```sh
python export_pages.py --base-path /angel-detailing
```

Результат находится в `docs/`. Эта папка создаётся автоматически и не хранится в Git.

Первичная загрузка проекта выполняется из двух архивов. Workflow распаковывает их, сохраняет обычные исходные файлы в репозиторий и удаляет установочные архивы из текущей версии.

## Запись

Запись доступна по телефону и через Telegram. Дополнительно форма подготавливает письмо, которое пользователь отправляет через своё почтовое приложение. Автоматической отправки заявок с GitHub Pages нет.

Фотографии, логотип и описания услуг взяты из материалов Angel Detailing. Основные изображения включены в проект; часть дополнительных фотографий проектов загружается с angeldetailing.ru.
